# Improsoft — сайт компании (v3.1 «BIR CHIZIQ»)

**v3.1 — визуальный ритм:** чередование фонов секций (штукатурка / тёплая
бумага / нефритовый тинт / два тёмных момента), демо-касса как настоящий
тёмный терминал, гигантское слово УЧЁТ./HISOB./LEDGER., узлы-водяные знаки
в главах продуктов, крупные цифры «1 / 2–3 / 4 / ∞» в таймлайне,
CTA-полоса перед FAQ.

**v3:** фирменные цвета взяты пипеткой из логотипа (зелёный `#5da47a`,
тёмно-серый `#363435`, тёмная ступень `#407d5b` для текста/кнопок — WCAG AA);
логотип воссоздан SVG в шапке и подвале (power-«o»), эмблема — в «О компании».
Новые разделы: интерактивное демо кассы (глава 02), «Один день с Impro»
с line-art-иллюстрациями (глава 07), «Что это даёт лично вам», FAQ (глава 11),
заготовка соцдоказательства (закомментирована — см. TODO в index.html:
нужны цифра заведений и названия клиентов).

Нарративный одностраничник для узбекской аудитории. Дизайн-концепция:
**одна непрерывная зелёная линия** проходит через всю страницу — рождается
в hero, завязывает смысловые узлы у каждого продукта (розетка гириха → Cafe,
штрих-код → Market, звезда-хатам → Pharm), становится маршрутом
Ташкент–Навои–Фергана на карте и в финале вычерчивает логотип.
Гирих как инженерия: одна линия по правилу порождает узор —
одна платформа порождает все продукты.

## Особенности

- **Три языка:** русский (по умолчанию), узбекский (латиница), английский.
  Переключение — «штампы» RU/UZ/EN в шапке, со шторкой-«печатающей головкой».
- **Интерактив:** дафтар (тап по рукописной записи превращает её в строку
  учёта), живой кухонный тикет, форма-чек с круглой печатью
  ПРИНЯТО / QABUL QILINDI при успехе, линия-прогресс слева.
- **Палитра:** штукатурка `#f6f8f4`, зелёные чернила `#0b2e23`, линия
  `#0e7a4d`, тёмная глава `#0d4a34`, бирюза `#1e9e8e` (≤5%).
- **Шрифты (Google Fonts):** Unbounded (заголовки), Golos Text (текст),
  PT Mono (чеки/цифры), Neucha (рукопись дафтара).
- **Без сборщиков:** чистый HTML/CSS/JS, лёгкий на дешёвых Android.
  При reduced-motion и без JS вся графика показывается дорисованной.

## Структура

```
index.html          — вся страница (тексты по умолчанию на русском)
css/styles.css      — стили, палитра в :root
js/i18n.js          — словари RU / UZ / EN (145 ключей, синхронны)
js/main.js          — язык, линия, дафтар, тикет, форма, липкая панель
assets/             — favicon, og-image
v1/                 — первая версия сайта (классический лендинг), архив
```

## Запуск локально

Откройте `index.html` в браузере — сервер не нужен.

## Как изменить тексты

Все тексты — в `js/i18n.js` в трёх словарях (`ru`, `uz`, `en`).
Ключ `data-i18n="..."` в HTML соответствует ключу словаря. Русские тексты
продублированы в `index.html` как значения по умолчанию — правьте оба места.
Перед тире в текстах используется неразрывный пробел (тире не начинает строку).

## Перед публикацией

1. **Домен:** замените `improsoft.uz` в `<head>` `index.html`
   (canonical + OG-теги) на рабочий домен.
2. **Telegram:** проверьте ссылку `https://t.me/improsoft` (шапка,
   липкая панель, блок заявки).
3. **Форма:** подключите отправку заявок — см. `TODO` в `js/main.js`
   (бэкенд, Telegram-бот или сервис форм).

# Improsoft — сайт компании (v4.0 «Impro SaaS»)

**v4.0 — новый дизайн (ноябрь 2026).** Клиент отказался от прежнего
визуального языка «BIR CHIZIQ» (рисованная линия, узлы-знаки, круги,
узор-гирих, повёрнутые бумажки). Сайт переделан в продуктовый SaaS-стиль:
светлый фон, карточки с мягкими тенями, пиктограммы в плитках и экраны
программы в рамках устройств. Экраны **повторяют настоящую программу Impro**
(Windows, интерфейс на русском): зелёная строка заголовка «Сменить
пользователя | IMPROCAFE | Кассир | Рабочая область», панель инструментов
с подписями капсом, цветные вкладки, таблицы «Итого за смену / Касса /
Общее поступление средств», экран продажи с розовыми плитками товаров и
клавишами F2/F3/F10, таблицы «Остатки товаров» и «Приход товаров».
Эталонные скриншоты программы — в папке `_ref/` (в git не попадает).

Интерактив сохранён и переодет: тетрадь → журнал операций (клик по записи,
«Провести все», «Начать заново», автопроведение первой записи на десктопе),
мини-касса в экране продажи (плитки блюд, чек с «−», способы оплаты
Наличные F2 / UZCARD F3 / PayMe / Click / Uzum / В долг, «Оплатить F10»,
номер чека, плавающий итог на телефоне), кухонный экран заказов (тап
«готовится» → «подано», автоцикл, живые часы), остатки товаров (кнопка
«Сканировать» уменьшает остаток), приход товаров с датами годности от
текущей даты (+17 / +2 / +9 месяцев). Движение: появление блоков при
прокрутке, счётчики цифр, лента возможностей, плавный FAQ, scrollspy,
прячущаяся шапка, наклон устройств и магнит кнопок (только мышь); всё
непрерывное на паузе вне экрана, при `prefers-reduced-motion` выключено.

Продукты называются Improcafe, Impromarket, Impropharm (у клиента есть ещё
Improhotel для гостиниц — на сайте пока не описан). Семь городов: главный
офис в Навои (+998 93 522 20 20, +998 88 218 88 80, improsoft@mail.ru),
представитель в Андижане (+998 97 413 03 64).

## Особенности

- **Три языка:** русский (по умолчанию), узбекский (латиница), английский.
  Переключение — сегмент-контрол RU/UZ/EN в шапке. Интерфейс внутри экранов
  программы остаётся русским (как сама программа), данные (блюда, товары,
  статусы) переводятся.
- **Палитра:** фон `#f7f9f8`, карточки `#fff`, текст `#363435`, зелёный
  логотипа `#5da47a`, тёмный зелёный `#407d5b` (кнопки, AA), тёмная полоса
  `#1f3a2d`; без `color-mix()` — только hex (старые Android WebView).
- **Шрифты (Google Fonts):** Manrope (заголовки, цифры), Golos Text (текст),
  Neucha (рукопись тетради), Poppins (словесный знак). Внутри экранов
  программы — системный Segoe UI.
- **Иконки:** инлайн-SVG-спрайт в начале `<body>`, `<use href="#i-…">`.
- **Без сборщиков:** чистый HTML/CSS/JS, лёгкий на дешёвых Android.
  Без JS всё видно и статично; при reduced-motion анимаций нет.

## Структура

```
index.html          — вся страница (тексты по умолчанию на русском)
css/styles.css      — стили: токены в :root, компоненты, экраны программы, адаптив
js/i18n.js          — словари RU / UZ / EN (241 ключ, синхронны)
js/main.js          — язык, шапка, reveal, счётчики, лента, тетрадь, касса, кухня, склад, даты партий, форма, scrollspy, наклон/магнит
assets/             — favicon, logo, og-image
send.php            — приём заявки → Telegram (нужен tg-config.php)
_ref/               — скриншоты настоящей программы (локально, не в git)
```

## Запуск локально

Откройте `index.html` в браузере — сервер не нужен.

## Как изменить тексты

Все тексты — в `js/i18n.js` в трёх словарях (`ru`, `uz`, `en`).
Ключ `data-i18n="..."` в HTML соответствует ключу словаря. Русские тексты
продублированы в `index.html` как значения по умолчанию — правьте оба места
(или прогоните скрипт синхронизации: статический RU = словарь).
Элемент с `data-i18n` не должен содержать дочерних тегов: смена языка
заменяет его текст целиком. Перед тире в текстах — неразрывный пробел.

## Заявки в Telegram

Форма отправляет заявки через `send.php` (PHP на хостинге) в Telegram-бота:

1. Создайте бота: в Telegram → `@BotFather` → `/newbot` → получите токен.
2. Напишите боту `/start` (или добавьте его в рабочую группу).
3. Скопируйте `tg-config.example.php` → `tg-config.php`, вставьте токен
   и chat_id. **Файл tg-config.php не публикуйте** (он в `.gitignore`).
4. Загрузите `send.php` и `tg-config.php` в public_html рядом с index.html.

Без PHP (локальное превью, GitHub Pages) форма честно предложит написать
в Telegram напрямую. Антиспам: honeypot-поле + не чаще одной заявки
в 15 секунд с одного IP.

## Перед публикацией

1. **Домен:** замените `improsoft.uz` в `<head>` `index.html`
   (canonical + OG-теги) на рабочий домен.
2. **tg-config.php:** создайте из example-файла и загрузите на хостинг
   (без него send.php вернёт ошибку, а форма предложит Telegram).
3. **Кэш:** при каждом деплое поднимайте `?v=` в ссылках на css/js.

## Деплой

Хостинг с PHP (cPanel и т.п.) — для приёма заявок. Без PHP сайт тоже
работает (Netlify, GitHub Pages), но форма только ссылается на Telegram.
